ICT Assistant - Multi-School Price Action Indicator

A free, open-source MT5 indicator that unifies nine trading schools (ICT, SMC, Market Maker Model, Wyckoff, Supply & Demand, Market Profile, Volume Profile, RTM, Al Brooks) into one chart tool. It is both an indicator and a teacher: clicking any object opens a Persian explanation panel with the rule behind it, what invalidates it, and how to verify the numbers by hand. Built on closed-bar analysis (no repaint), with per-timeframe registries and 21 rule validators.

Web3 Membership Access dApp

A membership access dApp where users sign in with an Ethereum wallet (SIWE) and the app decides what they can see from an on-chain membership registry. Sign-in is verified server-side, the protected dashboard renders only after both the session and the on-chain check pass, and the admin panel builds unsigned grant/revoke transactions that the admin's own wallet signs. The backend never holds keys and never broadcasts transactions. Testnet (Sepolia) MVP.
