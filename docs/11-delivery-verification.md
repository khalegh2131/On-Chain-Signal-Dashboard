# ۱۱ — تأیید تحویل: آزمون نسخهٔ منتشرشده

این سند پاسخ یک پرسش مشخص است: **آیا چیزی که روی گیت‌هاب منتشر شده واقعاً کار می‌کند؟** تا اینجا همه آزمون‌ها روی درخت کاری سازنده اجرا شده بودند؛ یک درخت کاری سالم می‌تواند به‌خاطر فایل‌های محلی که هرگز کامیت نشده‌اند، مخزن ناقصی تولید کند. پس شاخهٔ منتشرشده در یک پوشهٔ کاملاً تازه کلون و از صفر ساخته شد.

## ۱. زنجیرهٔ تأیید در سه لایه

| لایه | چه چیزی سنجیده شد | نتیجه |
|------|----------------------|--------|
| ۱. درخت کاری سازنده | typecheck، lint، prettier، آزمون، بیلد | همه سبز |
| ۲. کلون تازه از گیت‌هاب | `git clone --branch defi-portfolio-dashboard --depth 1` سپس `npm install` و اجرای دوبارهٔ همهٔ دروازه‌ها | ۱۷۰ فایل، ۱۰۴۴ بسته نصب شد، همه سبز |
| ۳. اجرای سرویس منتشرشده | `next start` روی همان کلون و درخواست هر مسیر | ۶ مسیر ۲۰۰، مسیر نامعتبر ۴۰۴، stderr خالی |

## ۲. نتیجه لایه ۲ — کلون تازه

```
git clone --branch defi-portfolio-dashboard --single-branch --depth 1
  https://github.com/khalegh2131/On-Chain-Signal-Dashboard.git
```

| بررسی | نتیجه |
|--------|--------|
| تعداد فایل در کلون (بدون `.git`) | ۱۷۰ (برابر با مخزن محلی) |
| HEAD | `e49d083` |
| `npm install` | ۱۰۴۴ بسته، کد خروج ۰ |
| `npm run typecheck` | کد خروج ۰ |
| `npm run lint` | بدون خطا و هشدار |
| `npx prettier --check .` | همه فایل‌ها منطبق |
| `npm run test` | ۲۰ فایل، ۲۹۷ تست، ۰ شکست |
| `npm run build` | کد خروج ۰، همان جدول مسیرها، JS مشترک ۹۰ کیلوبایت |

نکات مهمی که این آزمون اثبات کرد:

- `.env.example` در مخزن هست و `.env.local` **نیست** → قاعده نبود راز در مخزن واقعاً کار می‌کند.
- پروژه بدون هیچ فایل محلی بیلد می‌شود → مخزن خودکفاست و چیزی جا نمانده است.
- تعداد فایل کلون با مخزن محلی برابر است → `.gitignore` چیزی را که لازم است حذف نکرده.
