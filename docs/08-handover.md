## ۳. متغیرهای محیطی

| نام | الزامی؟ | کاربرد |
|-----|---------|---------|
| `NEXT_PUBLIC_ALCHEMY_API_KEY` | خیر (توصیه‌شده) | خواندن موجودی توکن، فراداده قرارداد و NFT. بدون آن، RPC عمومی جایگزین می‌شود که کندتر و محدودتر است. |

| `COINGECKO_API_KEY` | خیر | قیمت‌گذاری. بدون آن، سطح عمومی CoinGecko با محدودیت نرخ استفاده می‌شود. کلیدهای `CG-` خودکار به میزبان Pro هدایت می‌شوند. |

```

  (marketing)/    صفحه فرود
  (dashboard)/    داشبورد، پورتفوی، NFT، DeFi + loading/error هر مسیر

components/   رابط کاربری
  ui/             پایه‌های shadcn

  charts/         نمودار و اسپارک‌لاین
  nfts/           گالری، کنترل‌ها و کارت NFT
  defi/           موقعیت‌ها، کارت و جزئیات
lib/          منطق
  api/            کلاینت‌های بیرونی + سلسله‌مراتب خطا + دروازه SSRF

  mock/           داده دمو با بذر ثابت
  web3/           پیکربندی wagmi و هوک‌های کیف پول
```

**قاعده طلایی نگهداری:** منطق کسب‌وکار در `lib/services` می‌ماند، توابع خالص در `lib/utils`، و کامپوننت‌ها هیچ‌گاه مستقیم به یک ارائه‌دهنده بیرونی وصل نمی‌شوند. اضافه کردن یک ارائه‌دهنده جدید یعنی نوشتن یک کلاینت در `lib/api` و سرویس‌کردن آن، نه تغییر کامپوننت.

## ۶. کارهای متداول نگهداری

### افزودن یک زنجیره جدید
۱. یک ورودی در `CHAIN_METADATA` در `config/chains.ts` اضافه کنید (نام، اکسپلورر، زیردامنه Alchemy، شناسه CoinGecko، رنگ).
۲. اگر می‌خواهید به‌صورت پیش‌فرض خوانده شود، آن را به `ACTIVE_CHAINS` اضافه کنید.
هیچ تغییر دیگری لازم نیست؛ رابط کاربری، فیلترها و قیمت‌گذاری خودکار به‌روز می‌شوند.

### فعال کردن مِین‌نت
در `config/chains.ts` مقدار `ACTIVE_CHAINS` را به `[CHAIN_METADATA[1], CHAIN_METADATA[42161]]` تغییر دهید.

### افزودن پروتکل DeFi
یک تابع `readXPositions` در `lib/services/defi.service.ts` بنویسید که `PositionDraft` برگرداند و آن را به `Promise.all` در `fetchDefiPositions` اضافه کنید. ارزش‌گذاری خودکار انجام می‌شود.

### تنظیم TTL کش
مقدارهای `PRICE_TTL_MS` و مانند آن در `config/constants.ts` قرار دارند.

| نشانه | علت محتمل | کار |

| صفحه DeFi فقط یادداشت پوشش نشان می‌دهد | `GRAPH_API_KEY` تنظیم نشده | افزودن کلید، بدون تغییر کد |
| قیمت‌ها دیر به‌روز می‌شوند | کش ۵ دقیقه‌ای قیمت | کاهش TTL در `config/constants.ts` |

| بیلد با خطای ماژول‌های `@x402/*` | تغییر در زنجیره وابستگی RainbowKit | الگوی خنثی‌سازی در `next.config.mjs` را به‌روز کنید |

### چرا مستقیم روی `main` منتشر نشد

مخزن `On-Chain-Signal-Dashboard` از قبل میزبان صفحهٔ پورتفولیوی کارفرما است و تاریخچهٔ گیت آن **هیچ ریشه مشترکی** با این پروژه ندارد. `git push` به `main` با خطای زیر رد می‌شود:

```
! [rejected]  main -> main (non-fast-forward)
```

ادامه دادن با `--force` یعنی **پاک شدن صفحهٔ پورتفولیوی منتشرشده**؛ این یک عملیات بازگشت‌ناپذیر روی یک سایت عمومی است و انجام نشد. در عوض پروژه روی یک شاخهٔ **افزایشی و بی‌خطر** منتشر شد که قابل حذف و بازگشت است.

### کار باقی‌مانده روی مخزن

۱. فایل `.v2c/plugin_root` (وضعیت ابزار محیطی) به‌اشتباه وارد کامیت اول شد. دستور پاک‌سازی آن توسط محافظ ایمنی مسدود شد و نیازمند تأیید کارفرما است:

```powershell
git rm -r --cached .v2c
git commit --amend --no-edit
git push --force-with-lease origin main:defi-portfolio-dashboard
```

۲. برای یک خانهٔ تمیز و مستقل، بهتر است مخزن جداگانه‌ای (مثلاً `defi-portfolio-dashboard`) ساخته شود؛ با احراز هویت موجود، انتقال آن چند ثانیه است.
