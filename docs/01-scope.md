# ۰۱ — سند دامنه، هدف نهایی و مرزهای کار

## ۱. هدف نهایی

تحویل یک **داشبورد پورتفوی DeFi فقط-خواندنی و چندزنجیره‌ای** که یک آدرس کیف پول را می‌گیرد و دارایی‌های آن را در چند شبکه، همراه با قیمت، ارزش دلاری، ترکیب زنجیره‌ای، کلکسیون‌های NFT و موقعیت‌های DeFi (استخر نقدینگی، وام‌دهی، استیکینگ) نمایش می‌دهد — بدون اینکه هیچ‌گاه کلید خصوصی یا امضای تراکنش لازم باشد.

معیار «بهترین» در این پروژه: خروجی‌ای که (۱) با یک دستور `npm install && npm run dev` بالا بیاید، (۲) بدون هیچ کلید API هم قابل نمایش باشد، و (۳) رفتارش در مسیرهای خطا و حالت‌های خالی مشخص و آزمون‌شده باشد.

## ۲. در دامنه (آنچه تحویل شد)

| حوزه | شرح |
|------|-----|
| پایه پروژه | Next.js 14 (App Router) + TypeScript سخت‌گیر + TailwindCSS + shadcn/ui + wagmi v2 + viem + RainbowKit |
| لایه داده | کلاینت‌های Alchemy (RPC و NFT API)، CoinGecko، The Graph؛ کش TTL درون‌حافظه‌ای؛ backoff نمایی |
| لایه سرویس | موجودی چندزنجیره‌ای، قیمت‌گذاری با زنجیره جایگزین، NFT، موقعیت‌های DeFi، دفترچه واچ‌لیست |
| رابط کاربری | داشبورد، پورتفوی، NFT، DeFi، صفحه فرود؛ دارک‌محور با تأکید زمردی؛ اسکلتون/خطا/خالی برای هر سطح |
| کیفیت | ۲۵۲ تست خودکار (شامل تست تعاملی DOM)، typecheck، lint، prettier، بیلد تولیدی، آزمون دود سرور |
| مستندات | ۱۱ سند حاکمیتی و عملیاتی (همین پوشه) |

## ۳. خارج از دامنه (آگاهانه انجام نشد)

- **نوشتن روی زنجیره**: هیچ تراکنش، امضا، تأیید (approve) یا فراخوانی قرارداد تغییردهنده وضعیت وجود ندارد. کل محصول فقط-خواندنی است.
- **احراز هویت یا حساب کاربری**: هیچ سرور کاربر، session یا پایگاه داده‌ای نگهداری نمی‌شود.
- **پوشش کامل پروتکل‌های DeFi**: در نسخه ۱ تنها Uniswap v3، Aave v3 و Lido پوشش داده می‌شوند؛ بقیه پروتکل‌ها با نام و دلیل صریح گزارش می‌شوند، نه با عدد حدسی.
- **پشتیبانی از زنجیره‌هایی خارج از چهار زنجیره تعریف‌شده** (Ethereum، Arbitrum One، Sepolia، Arbitrum Sepolia).
- **قیمت‌گذاری توکن‌های شبکه آزمایشی**: CoinGecko شبکه‌های آزمایشی را نمایه نمی‌کند؛ این توکن‌ها بدون قیمت نمایش داده می‌شوند.
- **استقرار (deploy) و انتشار عمومی**: طبق سند دامنه، انتشار روی محیط بیرونی نیازمند تأیید جداگانه کارفرما است و انجام نشده.
- **هر تعهد حقوقی، مالی یا قراردادی** به نام کارفرما.

## ۴. فرض‌های ثبت‌شده

1. زنجیره‌های پیش‌فرض، شبکه‌های آزمایشی (Sepolia و Arbitrum Sepolia) هستند تا مصرف سهمیه RPC مِین‌نت در توسعه هدر نرود؛ مِین‌نت در کد تعریف شده و با یک تغییر کوچک فعال می‌شود.
2. برای **قیمت‌گذاری** توکن‌های مِین‌نت، CoinGecko شناخته‌شده‌ترین منبع عمومی است؛ برای **موجودی**، Alchemy. هر دو با کلید خالی هم قابل استفاده‌اند (با محدودیت نرخ).
3. داده‌های نمایشی (NFT، موقعیت‌های DeFi، پورتفوی نمونه) **واقعی‌نما اما ثابت** هستند و با اتصال کیف پول جای خود را به داده واقعی می‌دهند. هیچ‌گاه با داده واقعی اشتباه گرفته نمی‌شوند، چون در رابط کاربری با برچسب «دمو» مشخص شده‌اند.
4. محیط اجرا Node.js نسخه ۱۸.۱۸ یا بالاتر است (محیط تأییدشده: Node v22.22.0، npm 10.9.4 روی Windows).
5. کاربر تصمیم‌گیر نهایی است و تأیید صریح او پیش از تحویل نهایی لازم است (SM-10).

هر مرحله با یک **نسخه قابل اجرا** بسته می‌شود، نه با توضیح. معیار پذیرش: در پایان مرحله، `npm run build` سبز است و مسیرهای موجود پاسخ می‌دهند. جدول کامل در سند ۰۳ و نتیجه اجرا در سند ۰۴ ثبت شده است.
